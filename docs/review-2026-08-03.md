## Jak powtórzyć testy

```bash
docker compose up -d
docker compose restart api   # jeśli API po Maven ma pusty schemat

npm run test:api
npm run test:mobile-unit

# E2E — web na :8081 (Compose), mobile Expo web:
cd mobile && npx expo start --web --port 8082   # osobny terminal
npx playwright install chromium                 # raz
npx playwright test --project=web-desktop
npx playwright test --project=mobile-expo
```
