RacePortal ma być jednym miejscem odkrywania i obsługi startów motorsportowych w Polsce: kierowca znajduje wydarzenie, sprawdza wymagania względem własnego garażu i składa zgłoszenie; organizator publikuje imprezę i zarządza listą uczestników; administrator moderuje treści i role.

Wizja produktowa zakłada:

* publiczny katalog z trzema widokami (lista, mapa, kalendarz) na wspólnych filtrach;
* ujednolicony proces zapisu ze statusami i powiadomieniami e-mail;
* wyraźny podział ról USER / ORGANIZER / ADMIN (gość przegląda katalog bez konieczności zakładania konta);
* mobilną ścieżkę *discovery* (Expo) z konwersją zapisu na wersję webową;
* uruchamialne środowisko demonstracyjne (Docker Compose) oraz wdrożenie produkcyjne realizowane za pośrednictwem Cloudflare Tunnel.

Szczegóły warstw technicznych (aplikacja webowa React/Vite, API REST oparte o Spring Boot, baza danych MySQL, aplikacja mobilna Expo oraz współdzielone typy API w pakiecie packages/api-types) opisano w dalszej części pracy oraz w rozdziałach implementacyjnych. Kod źródłowy projektu utrzymywany jest w dedykowanym repozytorium.
